## ไฮไลต์ฟีเจอร์เด่นใน v1.0.35 & Minimal UI

- **ดีไซน์ใหม่ Warm Charcoal Minimal:** เรียบหรู สะอาดตา สบายตา ลดความรกรุงรัง ให้ความสำคัญกับโค้ดและงานตรงหน้า
- **สวิตช์ 3 โหมดแบบ Compact 3-Icon Switch:** สลับโหมด Agent, Code และ Chat ได้ในคลิกเดียว พร้อมคำอธิบายฟังก์ชัน
- **Agent Workspace & Clarifying Questions:** ระบบตรวจเป้าหมายงานก่อนเริ่มทำ เมื่อโจทย์กำกวม AI จะถามกลับพร้อมตัวเลือก (Multiple-choice) ก่อนวางแผนงาน
- **ตัวควบคุมสิทธิ์เครื่องมือและความปลอดภัย (Tool Permission Control):** สลับโหมดปลอดภัย (Safe Read-only) เพื่อให้อ่านไฟล์และวางแผนอย่างเดียว หรือโหมดลงมือทำ (Edit mode) เพื่อให้รันคำสั่งและแก้ไฟล์จริง
- **Cross-Agent Review & Security Audit:** ให้ AI ตรวจสอบโค้ดซึ่งกันและกัน (เช่น Claude เขียนแล้วให้ Antigravity หรือ Codex ช่วยรีวิวหาช่องโหว่) พร้อมระบบรักษาความปลอดภัยเครือข่าย Local Loopback และ Folder Trust
- **Self-Healing Automated Test Loop:** วนรอบรันทดสอบและซ่อมแซมโค้ดอัตโนมัติเมื่อเทสต์ล้มเหลว โดย AI จะวิเคราะห์ Failure Summary และดำเนินการแก้บั๊กจนกระทั่งผ่านทุกการทดสอบ
- **Curated Skills Ecosystem:** ติดตั้งและจัดการ Skill เพื่อขยายขีดความสามารถของ AI ได้ในคลิกเดียว รองรับคลัง Skill มาตรฐานจาก Anthropic, OpenAI, Vercel (skills.sh) และ Cloudflare Security Audit
- **Quick Provider Chat & Safe Mode:** เริ่มพิมพ์คุยกับ AI ได้ทันทีตั้งแต่เปิดแอป ไม่ต้องตั้งค่าโปรเจกต์ก่อน
- **Composer Options รวมศูนย์:** ปรับระดับความคิด (Effort), สิทธิ์การเขียนไฟล์ และรายละเอียดบัญชี AI ได้ในปุ่มเดียว พร้อมปุ่มลัด `Escape` เพื่อปิด
- **Unified History & Full-Text Search:** รวมประวัติการสนทนาทุกเซสชันของทุก AI ค้นหาข้อความได้ทั้งโปรเจกต์ และกรองตามผู้ให้บริการได้
- **ซ่อนเซสชันโดยไม่ต้องลบ (`EyeOff`):** พับเก็บเซสชันที่ไม่ใช้งานออกจากหน้าจอหลักเพื่อจัดระเบียบพื้นที่ โดยประวัติและโปรเซสยังคงทำงานต่อ 100%
- **Git Worktrees & Branch Switcher:** สลับ branch ได้อย่างปลอดภัย และสร้าง worktree พัฒนาหลายฟีเจอร์พร้อมกันโดยไฟล์ไม่ชนกัน พร้อมแถบ Smart Merge ช่วยรวมโค้ดกลับเข้า main
- **Ctrl + Click เปิด URL ทันที:** กด Ctrl+Click (หรือ Cmd+Click บน Mac) บนลิงก์ในช่องพิมพ์หรือข้อความแชท เพื่อเปิดเว็บเบราว์เซอร์ภายนอกทันทีเหมือนใน Claude App
- **Interactive Artifacts:** พรีวิวโค้ดสด (HTML/SVG/Tailwind/Mermaid) และทดสอบโค้ด React/JSX/TSX แบบอินเทอร์แอคทีฟ
- **Local Whisper Voice Typing:** พูดภาษาไทยเพื่อพิมพ์ข้อความ แปลงเสียงบนเครื่อง 100% เสียงไม่ออกนอกเครื่อง
- **Usage Tracker:** ตรวจสอบโควตาคงเหลือของ Claude, Codex, Antigravity แบบเรียลไทม์

## ติดตั้ง

### Windows
1. ดับเบิลคลิก `SuperAi-RAKKYXD-Setup.exe` แล้วรอสักครู่
2. เลือกโฟลเดอร์ติดตั้ง ค่าเริ่มต้น `%LOCALAPPDATA%\Programs\SuperAi-RAKKYXD` ไม่ต้องใช้สิทธิ์ Admin
3. เลือกว่าจะสร้างทางลัดบนเดสก์ท็อป และเปิดโปรแกรมเมื่อติดตั้งเสร็จหรือไม่ แล้วกด **ติดตั้ง**

<p align="center">
  <img src="images/installer.png" alt="ตัวติดตั้ง Windows" width="430" />
  <img src="images/installer-done.png" alt="ติดตั้งเสร็จ" width="430" />
</p>

ตัวติดตั้งเพิ่มทางลัดใน Start Menu และรายการใน **Settings → Apps** ให้เรียบร้อย

> **ถ้าขึ้น “Windows protected your PC”** ให้กด **More info → Run anyway** (เนื่องจากโปรแกรมยังไม่มีใบรับรองดิจิทัลแบบชำระเงิน)

### macOS 11 ขึ้นไป
เปิดไฟล์ `.dmg` แล้วลาก **SuperAi & RAKKYXD** ไปที่โฟลเดอร์ **Applications**

> **ถ้า macOS ไม่ยอมเปิดครั้งแรก** ไปที่ **System Settings → Privacy & Security** แล้วกด **Open Anyway**

## อัปเดตและถอนการติดตั้ง

- **อัปเดตอัตโนมัติ:** โปรแกรมตรวจเวอร์ชันใหม่ให้เองตอนเปิดและทุก 30 นาที หากมีเวอร์ชันใหม่จะแจ้งเตือนที่มุมล่างขวา สามารถกดอัปเดตได้ทันทีโดยไม่ต้องดาวน์โหลดใหม่เอง
- **งานไม่หาย:** เมื่ออัปเดต โปรแกรมจะรอให้ AI ตอบเสร็จก่อน แล้วเปิดแท็บและประวัติเดิมกลับมาคุยต่อได้อย่างต่อเนื่อง
- **ถอนการติดตั้ง (Windows):** ไปที่ **Settings → Apps → Installed apps → SuperAi & RAKKYXD → Uninstall**
- **ถอนการติดตั้ง (macOS):** ลากแอปจากโฟลเดอร์ Applications ลงถังขยะ
